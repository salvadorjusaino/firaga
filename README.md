# FIRAGARECORDS.COM


[Demo](https://salvadorjusaino.github.io/firaga-records/)


## Installation

Install dependencies:

```
npm install
```

Compile the code for development and start a local server:

```
npm run dev
```

Create the build:

```
npm run build
```
